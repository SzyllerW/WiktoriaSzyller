Soror – Boss Rush Project

About the Project

Soror is a boss-rush passion project created as part of my bachelor's thesis. The game was developed by a 4-person team, where I served as the enemy AI and combat systems programmer.

I implemented the entire boss behaviour architecture, advanced melee collision detection, attack windows, posture/stagger logic, and the AOE telegraph system. Additionally, I built a custom Unity Editor window for placing and aligning AOE telegraphs to floors and level geometry, improving workflow and designer iteration speed.

Code Highlights

Sub-stepped sword collision (precise melee detection)

The sword path is sampled multiple times per frame using interpolated capsule checks. This prevents tunneling issues and ensures accurate, frame-independent melee hits. The blade position is lerped between previous and current frame, and collisions are checked along the entire trajectory.

Adaptive rotation blending during attacks

Before striking, the boss rotates faster to telegraph its attack, then blends into a slower tracking rotation during the attack window. This makes combat readable but still threatening, improving overall game feel and timing clarity.
