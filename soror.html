SOROR
Boss Rush

About the Project

Soror is a passion-driven boss rush created as part of my bachelor's thesis. Developed by a 4-person team, where I serve as the AI & gameplay programmer. I created the enemy behaviour logic, posture system, AOE mechanics, and built a custom Unity Editor Window for aligning AOE patterns to the arena.

Code Highlights

Sub-stepped melee collision: the sword’s movement is sampled multiple times per frame using capsule checks to guarantee precise hit detection.
Adaptive rotation blending for readable attack telegraphs and smooth timing transitions.
