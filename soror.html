Soror – Boss Rush Project

About the Project

Soror is a boss-rush action game created as a passion project for my bachelor's thesis. The game was developed by a 4-person team, where my role focused on:

  • programming enemy AI and combat logic
  • implementing AOE patterns & telegraphs
  • creating a custom Unity Editor window to align AOE shapes to floors and level geometry

My work centered around gameplay feel, boss behaviours, attack pacing, and responsive parry windows.

Gameplay Video

Code Highlights

Sub-stepped melee collision: the sword’s motion is sampled multiple times per frame using capsule checks along the blade arc, preventing tunneling and ensuring precise hit detection.
Adaptive rotation blending: fast anticipation turn-in followed by slower tracking during the attack window, creating readable but dangerous boss attack arcs.
